Distribue les tickets sur GitHub Projects étape par étape.

Lis `_orcl/workflows/push-kanban/workflow.md` pour comprendre le workflow complet.

<execution>
Pour chaque étape du workflow :
1. Lis UNIQUEMENT le fichier step en cours (pas les suivants)
2. Exécute les instructions du step
3. Quand le step est terminé, lis le step suivant
4. Ne saute jamais une étape

Commence par lire `_orcl/workflows/push-kanban/steps/step-01-prerequis.md`.
</execution>

<constraints>
<do-not>Ne jamais charger tous les steps d'un coup.</do-not>
<do-not>Ne jamais créer d'issues sans vérifier les prérequis.</do-not>
<do-not>Ne jamais créer d'issues en doublon.</do-not>
</constraints>
