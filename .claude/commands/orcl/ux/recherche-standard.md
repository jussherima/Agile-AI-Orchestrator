Lis `_orcl/workflows/recherche-standard/workflow.md` pour comprendre le workflow complet.

<execution>

1. Lis UNIQUEMENT le fichier step en cours (pas les suivants)
2. Exécute les instructions du step
3. Quand le step est terminé, lis le step suivant
4. Ne saute jamais une étape

Commence par lire `_orcl/workflows/recherche-standard/steps/step-01-contexte.md`.
</execution>

<constraints>
