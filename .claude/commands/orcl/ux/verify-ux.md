Audite et valide un design UX existant, étape par étape.

Lis `_orcl/workflows/verify-ux/workflow.md` pour comprendre le workflow complet.

<execution>
Pour chaque étape du workflow :
1. Lis UNIQUEMENT le fichier step en cours (pas les suivants)
2. Exécute les instructions du step
3. Quand le step est terminé, lis le step suivant
4. Ne saute jamais une étape

Commence par lire `_orcl/workflows/verify-ux/steps/step-01-charger.md`.
</execution>

<constraints>
<do-not>Ne jamais charger tous les steps d'un coup.</do-not>
<do-not>Ne jamais sauter une étape.</do-not>
<do-not>Ne jamais valider un design avec des problèmes de sévérité 4 (catastrophique).</do-not>
<do-not>Ne jamais ignorer l'accessibilité WCAG AA.</do-not>
</constraints>

Si besoin de référence approfondie → `brain/ux-ui/ORCL_UX_STANDARDS.md`.
