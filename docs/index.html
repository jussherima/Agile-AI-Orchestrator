Qu'est-ce qu'ORCL ?

Un framework qui transforme votre IDE en agence de développement complète.

ORCL installe dans votre projet 3 agents IA spécialisés — Product Manager, Developer et UX/UI — qui collaborent pour couvrir le pipeline agile complet : de la validation du cahier des charges au découpage en tickets, du push sur GitHub Projects à l'implémentation guidée avec code review et audit de sécurité. Zéro dépendance, configuration automatique, compatible Claude Code et OpenCode.

Installation

Une seule commande, zéro configuration.

# Installation initiale
npx orcl-ai install

# Mise à jour (préserve vos données)
npx orcl-ai update

# Mise à jour forcée (réinstallation complète)
npx orcl-ai update --force

Installe les agents, commandes, skills et règles dans .claude/, .opencode/ et _orcl/.

Les 3 Agents

Chaque agent est un expert dans son domaine, avec sa propre base de connaissances.

📋

Product Manager

Valide les cahiers des charges, crée les PRD, découpe en tickets et pousse sur GitHub Projects. Applique IEEE 830 / ISO 29148.

/orcl/agents/pm /orcl-pm
⚡

Developer

Implémente les tickets, review le code, crée les tests et audite qualité/sécurité/performance. Applique Clean Code, SOLID, OWASP.

🎨

UX/UI Specialist

Recherche les standards, crée les livrables UX, audite les designs. Applique Nielsen, WCAG 2.2, Material Design 3.

Audit

1. Validation CDC

Analyse du cahier des charges selon IEEE 830. Détecte les ambiguïtés, manques et incohérences. Produit un rapport avec des STOP clairs.

2. Découpage en tickets

Décompose le CDC en thèmes → epics → user stories INVEST. Découpage vertical end-to-end, chaque ticket traverse toutes les couches.

3. Push GitHub Projects

Crée le repo, configure le board Kanban, pousse les tickets avec labels, priorités, story points et itérations.

4. Implémentation & Audit

Implémente ticket par ticket avec TDD, code review SOLID et audit sécurité OWASP. Couverture de tests ≥ 80%.
