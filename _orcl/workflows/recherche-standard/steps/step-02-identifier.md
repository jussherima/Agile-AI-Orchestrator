<step order="2" name="identifier">
  <objective>Identifier les normes, heuristiques et guidelines applicables.</objective>

  <process>
    Pour chaque catégorie, évaluer la pertinence :

    **Normes obligatoires (toujours)** :
    - WCAG 2.2 (niveau AA minimum)
    - Heuristiques de Nielsen (10)
    - Lois UX applicables (Fitts, Hick, Miller, Doherty)

    **Guidelines plateforme (selon la cible)** :
    - iOS → Apple Human Interface Guidelines
    - Android → Material Design 3
    - Web → pas de guideline unique, mais conventions web standards
    - Desktop → Fluent Design (Windows) ou Apple HIG (macOS)
    - Multi-plateforme → Material Design 3 comme base commune

    **Normes sectorielles** :
    - Santé → HIPAA UX considerations, lisibilité renforcée
    - Finance → sécurité visuelle, confirmation renforcée
    - Éducation → gamification, progression visible, accessibilité enfants
    - E-commerce → conversion, confiance, performance perçue
    - Secteur public → RGAA (France), accessibilité AAA si possible

    **Normes ISO (si le client l'exige)** :
    - ISO 9241-110 pour les principes d'interaction
    - ISO 25010 pour la qualité produit
  </process>
