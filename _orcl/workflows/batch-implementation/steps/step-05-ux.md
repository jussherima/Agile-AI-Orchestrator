<step order="5" name="ux">
  <objective>Définir l'UX/UI du projet.</objective>

  <process>
    Exécuter les workflows UX en mode inline et condensé :

    **1. Standards (condensé) :**
    - Identifier les standards applicables (WCAG AA, Material/HIG, normes sectorielles)
    - Produire la checklist de règles concrètes
    - Sauvegarder dans `_orcl/output/ux/standards-[nom].md`

    **2. Patterns UI (condensé) :**
    - Lister les écrans nécessaires
    - Définir la navigation (bottom nav, sidebar, etc.)
    - Inventorier les composants par écran
    - Recommander le design system (Material, HIG, etc.)
    - Définir les fondations (couleurs, typo, spacing)
    - Sauvegarder dans `_orcl/output/ux/patterns-ui-[nom].md`

    **3. Livrables UX (condensé) :**
    - Créer les personas (3-5 max)
    - Définir les user flows critiques
    - Structurer le sitemap
    - Produire les wireframes textuels des écrans clés
    - Spécifications d'interaction et accessibilité
    - Sauvegarder dans `_orcl/output/ux/[nom]/`

    Annoncer : "✓ UX défini : [N] personas, [M] écrans, [P] flows. Scaffolding du projet..."
  </process>

  <next>Passer à step-06-stack.md</next>
</step>
